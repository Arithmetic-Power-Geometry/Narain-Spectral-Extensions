Every phase uses exact tests, independent evidence, verified references, preserved negative results, GitHub commits and a strict GO/REVISE/NO-GO gate. A failed conjecture is not to be presented as a theorem.

P11: Reproduce P01-P09 checkers verbatim from a pinned checkout. Preserve stdout, stderr, exit codes, hashes, environment, JSON comparisons and failures. Verify the complete P02 polynomial classification and the separate Paper I interval certificate.

P12: Formalize parity, conformal spin, oriented Narain equivalence and O(d,d;Z). Prove the invariance assumptions needed for a spin-refined duality obstruction; test adversarial symmetries.

P13: Test whether coupled T3/T4 examples are truly indecomposable under integral transformations. Give a complete invariant-based proof or report only bounded-search evidence.

P14: Certify or refute an open-neighborhood stability theorem. Audit all lower-energy degeneracies as rational functions; derive a uniform charge bound and interval enclosures. Preserve counterexamples.

P15: Extend the coupled T6 exact search above E=2, with completeness bounds, resource logs and first-threshold proof if a witness exists.

P16: Develop precise finite-data rigidity and inverse-spectral identifiability statements; test necessary versus sufficient conditions and prior counterexamples.

P17: Independent novelty kill-test, theorem-by-theorem primary literature matrix, metadata validation and clean-room re-execution.

P18: Final publication gate. Only outline or draft a manuscript after reproducibility, theorem, novelty, equivalence and interpretation gates pass.

For each phase save append-only evidence/Pxx code, outputs, failure logs, proofs and reference verification. Commit only to Arithmetic-Power-Geometry/Narain-Spectral-Extensions and verify readback. Never assert a proof that has not been established.
